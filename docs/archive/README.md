# 과거 자료 보관

> 상태: 원본 보존 · 최종 수정: 2026-11-11 · 작성: Codex

사용자가 제공한 ZIP 3개를 아래 폴더에 풀어 원래 파일 내용을 보존했다. ZIP 컨테이너 자체는 중복 저장하지 않았다. Markdown, CSV, HWPX, 이미지, 지도 파일을 포함한다. 내부의 과거 지시·회의 역할 배정은 현재 작업 지시가 아니다.

| [sources/project-management/](sources/project-management/) | `7ae17c43-75c8-454e-9fc3-2a3774fc4815_ExportBlock-ca4ccecf-d290-452b-961f-0976d3fab549.zip` | 총괄·1층·2층 기획, 1층 대본, 프로젝트 관리 표 |
| [sources/game-development/](sources/game-development/) | `fe24f7fa-41ff-47db-9473-fbe85abf5875_ExportBlock-e906b5d0-23ce-462a-b4ba-1380a51120d6.zip` | 기획 사본, 2026년 회의록, 케인·릴리스 설정, 단편소설 |

중복 자료도 출처별로 유지했다. 요약은 [통합 기획](../game-design.md)에 작성했다. HWPX는 내부 XML의 본문 텍스트를 검토했으며, 문서의 이미지·레이아웃은 시각 검증하지 않았다. 지도 이미지도 아직 플레이 공간과 대조하지 않았다.

내보낸 Markdown에는 제공되지 않은 페이지를 가리키는 링크가 있을 수 있다. 원본 링크를 임의로 고치거나 없는 내용을 복원하지 않는다.

기존 개발 기록은 원래 위치에 유지한다: [changelog](../changelog.md), [버그 기록](../bugfix-spawnposition-controlblocked.md), [씬 입구 ADR](../adr/0001-scene-entrance-refactor.md). ADR은 설계 선택과 이유를 남긴 기록이다.
