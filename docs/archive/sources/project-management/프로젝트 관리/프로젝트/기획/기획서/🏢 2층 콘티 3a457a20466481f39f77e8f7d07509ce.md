# 🏢 2층 콘티

> 작성일: 2025-11-11
> 

## 개요

- 맵 구성(방 개수·위치)은 1층과 동일 (추후 추가 예정)
- 2층의 괴물: **눈 귀신**

## 눈 귀신 특성

- 플레이어의 랜턴 불빛을 보면 즉시 달려와 즉사시킴
- 한 번 존재를 들키면 벗어날 방법은 1층으로 내려가는 것뿐
- 접촉 자체로는 죽지 않음 (그냥 지나가는 것은 가능) → 다만 매우 빠른 속도로 맵을 순찰하고 있어 랜턴을 켜면 즉시 달려와 사망

### 파훼법

- 2층 클리어 후 1층 왼쪽에서 **카메라** 획득
- 카메라는 화면 전체를 밝혀주되 랜턴보다 흐리게 보이며, 아이템의 밝은 빛 표시는 보이지 않음
- 카메라 사용 시 귀신은 뚜렷하게 보여야 함
- 이 카메라는 최종전(지하)에서도 재사용되는 아이템

### 연출 디테일

- 1층 클리어 후 2층으로 올라올 때 "딸그락" 등 효과음으로 1층에 변화가 생겼음을 암시

## 맵 구조

- 방은 총 2개: 계단 기준 왼쪽부터 **방 2-1 → 방 2-2**
- 방 2-1과 방 2-2 사이에 **센서** 존재
    - 센서에 노출되면 삼각형 모양 빛이 비침 → 귀신이 즉시 접근해 사망
    - 센서뿐 아니라 아이템 위치 확인 등 랜턴을 드는 모든 행위가 감지 대상에 포함
    - 회피를 위해서는 방 2-1의 아이템 사용 필요

## 방 2-1

- 방 콘셉트: 2층 컨셉(눈 귀신)에 맞춰 창문이 칠흑같이 어두운 **cowl**(가톨릭/정교회 수도사가 입는 후드 달린 일체형 로브)로 암막커튼처럼 가려져 있음
- **cowl 획득 시**: 센서 구간에서 커튼(cowl)으로 몸을 덮어 귀신이 달려오지 않도록 회피 가능
- **판정**: 불빛에 노출된 후 1초 안에 cowl을 사용하지 않으면 사망. 사용 시 총 3초간 빛이 유지되며, 빛이 꺼진 뒤에야 이동 가능
