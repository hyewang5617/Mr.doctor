# 2025 플럼 프로젝트 콘티 1차

2025 플럼 프로젝트 콘티 1차

2025-07-05

박관호

장르 : 공포

개발 : 유니티 2D

그래픽 수준 : 일러스트풍

컨셉 : 폐병원

게임 진행방식 :

- 반교의 게임 진행 방식을 모티브함

- 횡 스크롤로 캐릭터가 움직임, 이를 통해 스토리와 퍼즐형식의 게임을 진행함 - 인벤토리에 아이템을 넣어둘 수 있게함, 아이템을 사용하여 스토리를 진행하는 방식 - 문을 열거나 아이템을 줍고 사용하는 상호작용 키가 필요함

- 플레이어 시야는 제한시켜야함 (맵 전체 보여주기 X)

이벤트 :

- 괴물이 쫒아온다. 쫒아오는 괴물을 피해 다른 이벤트를 발생시켜서 도망간다 (맵이동 또는 아이템 사용)

- 열쇠등의 아이템을 사용하여 잠긴 문을 열거나 괴물을 쫒아낼 수 있음

- 문을 열어서 들어가거나 윗층, 아래층을 계단을 통해 이동하기

- 특정 맵에 존재하는 NPC를 통한 대화 또는 사물과의 상호작용의 혼잣말 같은 것 이는 플레이어가 알아차리기 쉽게 표시를 두어야함(반교에 보이는 그런 대화)

- 괴물에게 잡히거나 잘못된 루트로 스토리가 진행될때의 죽음이벤트 ( 화면에 깜놀 포인트 주기)

- 스토리가 진행됨에 따라 보이지 않던 것들이 보임 이때 맵이 바뀌어야함 처음에는 평범한 병원이지만 기억을 찾을수록 폐병원이 됨.

스토리틀 :

1. 과거 회상

처음 플레이어의 상황을 인지할 수 있을정도의 스토리를 보여줌 플레이어는 과거의 기억 일부분이 사라짐

2. 병실 내부

주인공은 폐병원 병실에서 깸 이때 간단한 조작등을 알려줄 것.

3. 복도

병실에서 나와서 왜 자기가 여기 있는지 확인함 이때 탈출구가 잠겨있음을 확인함

4. 건물 전체

플레이어는 건물을 돌아다니며 아이템을 수집하고 맵을 해금하면서 자신의 과거 기억과 자신이 갇혀있는 이유를 알아감, 또한 여기서 귀신과의 추격이 필요함 또는 상호작용 5. 엔딩

사실 주인공은 폐병원 의사였고 모종의 이유로 환자들을 죽여와서 결국 기사에까지 실리며 의사직을 박탈당함 피해자의 유족중 한명이 어떠한 방법으로 주인공의 기억을 지우고(약물 등이 있겠음) 피해자의 기분을 느껴보라고 가둬놓은 것임. 결국 도망치다가 악당을 죽이고 기억을 온전히 찾은 주인공은 신분세탁을 하고 의사의 활동을 이어감

디자인 컨셉 및 감정선:

1. 혼란

자신이 갑자기 병원에 있는 이유를 모르는 플레이어는 폐병원이 아니라 일반 병원으로 보임주인공은 병원에 혼자있는 것에 의문을 느낌

2. 공포

맵을 탐험하며 보이는 귀신들이 주인공을 원망하거나 싫어함에 당황과 무서움을 느낌 여기서부터 보이지 않던 핏자국이나 힌트가 보임 예를 들어 곤지암에 나왔던 살자 -> 자살 이런 이벤트

주인공은 기억의 일부분 즉 자신이 저질렀던 악행의 일부분이 보여져 고통스러워 함. 이때 주인공은 선한 성격을 가졌음 따라서 맵이 더 기괴해짐

3. 기억의 일부분 찾기

4. 온전한 기억 찾기

엔딩에 가까워 지며 맵이 완전한 폐병원으로 변하고 사악한 본성을 찾게된 주인공 이때부터는 희열과 기쁨을 느낌

5. 엔딩

주인공은 결국 본성을 찾은 상태로 신분을 세탁하므로 귀신 한이 맺힌 느낌이 들게하며 신문보도가 나온다거나 함
