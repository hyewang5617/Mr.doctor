# 프로젝트 문서

> 상태: 통합 초안 · 최종 수정: 2026-11-11 · 작성: Codex

현재 목표는 **시작부터 엔딩까지 플레이 가능한 하나의 게임**이다. 이번 정리는 사용자가 승인한 문서 정리이며, 새 게임 규칙의 확정을 뜻하지 않는다.

| 순서 | 문서 | 목적 |
| --- | --- | --- |
| 1 | [통합 기획](game-design.md) | 핵심 컨셉과 결정할 사항 |
| 2 | [스토리·진행표](story-and-flow.md) | 구간별 목표·해금·실패 흐름 |
| 3 | [구현 현황](implementation.md) | 코드로 확인한 사실과 검증 공백 |
| 4 | [로드맵](roadmap.md) | 추천 작업 순서와 완료 기준 |
| 참고 | [과거 자료 안내](archive/README.md) | 첨부 원본과 기존 개발 기록 |

문서에서 **현재 목표**는 사용자 요청, **과거 기획**은 첨부 자료 내용, **코드 확인**은 정적 검토 결과, **제안**은 승인되지 않은 추천, **미정**은 선택이 필요한 항목이다. 문서 날짜만으로 기획의 우선순위를 확정하지 않는다.

기존 [변경 기록](changelog.md), [스폰·조작 버그 기록](bugfix-spawnposition-controlblocked.md), [씬 입구 설계 기록](adr/0001-scene-entrance-refactor.md)은 링크 보존을 위해 이동하지 않았다. 현재 구현 판단은 구현 현황과 실제 코드를 기준으로 한다.
