# 스토리와 진행표

> 상태: 통합 초안 · 최종 수정: 2026-11-11 · 작성: Codex

## 기억 공개 설계 — 다음 기획 작업

각 구간마다 다음 다섯 칸을 채운다. 아직 새로운 사건을 확정하지 않았다.

1. 플레이어가 현재 믿는 사실
2. 발견하는 증거와 대사
3. 새로 드러나는 진실
4. 병원·주인공의 변화
5. 다음 행동을 유도하는 목표

## 저장과 재도전 — 제안

- 탐험 중 퍼즐을 닫는 것, 퍼즐 실패, 사망, 세이브 불러오기를 구분한다.
- 각 경우에 유지할 아이템·진행 단계·귀신 위치·연출 완료 상태를 표로 정한 뒤 구현한다.
- 사망 직전 상태를 무조건 복원해 반복 사망하는 상황을 피하고, 안전한 체크포인트를 둔다.
