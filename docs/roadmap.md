# 완성 로드맵

> 상태: 제안 · 최종 수정: 2026-11-11 · 작성: Codex

이번에 승인된 범위는 문서 통합이다. 아래 단계는 추천이며 아직 구현 승인을 뜻하지 않는다. 일정은 실행 검증 뒤 추정한다.

| 단계 | 작업 범위 | 완료 기준 |
| --- | --- | --- |
| 0. 자료 정리 | 원본 보존, 기획·진행표·구현 현황·규칙 정리 | 원본과 요약을 찾을 수 있고 미정 항목이 구분됨 |
| 1. 실행 상태 확인 | 에디터·CLI 연결, 컴파일, 주요 씬·참조 확인 | 실제 재현 가능한 정상·오류 목록과 화면 확보 |
| 2. 1층 완성 | D-03 선택, 대화·픽업·퍼즐·추격·재도전 안정화 | 시작부터 2층까지 플레이 가능, 저장·불러오기 후 진행 가능 |
| 3. 전체 진행 연결 | D-01·02·05·06·07 선택, 2층~엔딩을 임시 연출로 연결 | 처음부터 엔딩 하나와 타이틀 복귀까지 도달 가능 |
| 4. 구간별 개선 | 감각별 귀신 규칙, 단서·배경 변화·음향·연출 | 각 규칙을 배우고 적용할 수 있고 막히는 구간이 없음 |
| 5. 배포 검증 | 목표 플랫폼 빌드, 조작 안내·크레딧·사용 에셋 확인 | 에디터 밖에서 새 게임·이어하기·사망·엔딩 검증 |

## 다음 추천 작업

**1단계의 실행 상태 확인**을 먼저 한다. 기획 미정 항목이 많아도 기존 프로젝트의 실행·참조·1층 진행은 조사할 수 있다. 버전 업그레이드나 대규모 리팩터링(구조를 바꾸는 작업)은 오류 목록을 확보한 뒤 판단한다.

1층 구현에 들어가기 전에는 자물쇠 규칙과 사망 시 복원 범위를 사용자와 선택한다. 전체 연결 전에는 나머지 기획 선택 사항을 정한다.

## 완성의 기준 — 제안

- 새 게임으로 시작해 외부 조작 없이 엔딩 하나까지 도달한다.
- 죽어도 안전한 지점에서 다시 도전할 수 있다.
- 저장·불러오기 뒤 필수 아이템과 진행 상태가 일치한다.
- 대화·퍼즐·일시정지에서 조작이 영구적으로 잠기지 않는다.
- 빌드에서 시작 화면, 조작 안내, 종료, 크레딧이 작동한다.
- 임시 그림·소리와 최종 에셋을 구분하고 사용 권한을 확인한다.
