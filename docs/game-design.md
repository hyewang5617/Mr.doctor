# 통합 기획

> 상태: 통합 초안 · 최종 수정: 2026-11-11 · 작성: Codex

## 현재 목표

중단된 프로젝트를 이어서 엔딩까지 완성한다. 우선 기존 기능을 살리고 전체 진행을 연결한다. 플랫폼, 목표 플레이 시간, 출시 방식은 미정이다.

## 과거 기획의 핵심

- 폐병원을 배경으로 한 횡스크롤 2D 공포·탐험·퍼즐 게임. 일러스트풍 그래픽과 제한된 시야를 지향한다.
- 아이템을 수집·사용해 문과 구간을 해금한다. 대화·일기·추격으로 기억을 드러낸다.
- 평범해 보이던 병원이 기억 회복에 따라 기괴한 폐병원으로 변한다.
- 주인공은 피해자로 보이지만 실제로 환자들을 해친 의사다. 과거 결말은 기억을 되찾고 탈출해 신분을 바꾸어 의사 활동을 재개하는 내용이다.
- 1층은 소리, 2층은 빛·시야, 3층은 냄새를 중심으로 한 귀신 기믹을 구상했다. 지하에서는 다른 귀신을 흡수한 입 귀신과 최종전을 구상했다.

## 기획 충돌과 빈칸

| ID | 쟁점 | 현재 정리 |
| --- | --- | --- |
| D-01 | 감금한 사람 | 초기 총괄안은 피해자 유족, 1층 콘티는 탈출한 환자. 선택 필요 |
| D-02 | 카메라 획득 시점 | 1층 해금 후 재방문안과 2층 클리어 후 획득 문구가 충돌. 2층 공략 전에 얻도록 정리하는 것을 제안 |
| D-03 | 1층 퍼즐 | 과거안은 5단계·중단 유지·실패 시 한 단계 후퇴. 현재 코드는 다름. 적용 규칙 선택 필요 |
| D-04 | 귀신의 신체 설정 | 없는 감각기관과 강화된 능력의 관계를 설명할 필요 |
| D-05 | 3층·지하 | 아이템, 퍼즐, 실패·클리어 조건과 최종전 절차 미정 |
| D-06 | 결말 | 과거 결말 유지 여부, 최종 상대와 탈출 과정, 엔딩 후 처리 미정 |
| D-07 | 제작 범위 | 플랫폼·플레이 시간·필수 방 수·추가 엔딩 여부 미정 |

## 개선 제안

- 먼저 엔딩 하나를 가진 짧은 전체 흐름을 만든다. 추가 엔딩과 선택 구간은 이후 판단한다.
- 각 구간은 목표 → 안전한 규칙 학습 → 위협 속 활용 → 완료와 기억 공개 순으로 설계한다.
- 2층의 1초 대응·즉사 규칙은 첫 조우 전 예고와 가까운 재도전 지점을 마련한다.
- 기억 공개마다 단서, 주인공 반응, 배경 변화, 새 목표를 하나씩 연결한다. 반전 설명만 마지막에 몰아넣지 않는다.
- 배경 전체를 여러 벌 만들기 전에 조명·소품·음향 변화로 병원 변화를 시험한다.
